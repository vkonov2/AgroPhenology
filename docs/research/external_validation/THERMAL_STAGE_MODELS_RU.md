# Публичные модели стадий насекомых: реализация и границы проверки

10 ноября 2026 года. Реализован рабочий расчёт температурных переходов
трёх групп вредителей; у капустной моли сохранены два отдельных варианта
для разных растений-хозяев. **Биологическая внешняя валидация этих адаптеров
не выполнена:** в текущей коллекции нет подходящей последовательной разметки
соответствующих переходов и/или наблюдённой точки отсчёта. Численных метрик
предсказания вредителя, recall или ложных тревог здесь нет.

Код — `src/agro_phenology/external_thermal_stages.py`, тесты —
`tests/test_external_thermal_stages.py`. Старые формулы и frozen registry
не менялись. Реальные сообщения не отправлялись.

## Что реализовано

| Model ID | Переход и точка отсчёта | Параметры из источника | Статус метода |
|---|---|---|---|
| `codling_ncstate_thresholds` | *Cydia pomonella*: начало/конец отрождения из яиц, после наблюдённого взрослого trap-biofix | NC State: 1-е поколение 350/1050 °F·дней, 2-е — 1300/2600; расчёт 50/88 °F из UC IPM | Явная комбинация порогов NC State и single-sine horizontal калькулятора UC IPM; не тождество закрытому коду NC State |
| `cabbage_maggot_uw` | *Delia radicum*: появление 1/2/3-го поколения взрослых, от наблюдённого оттаивания почвы | База 43 °F; 300/1476/2652 °F·дней | Single-sine без верхнего ограничения — явно указанная адаптация: UW не задаёт точный вычислительный метод |
| `diamondback_harcourt_cabbage` | *Plutella xylostella*: яйцо → взрослая особь, наблюдённая когорта яиц; капуста | База 7,3 °C; 283 °C·дня | В исходном исследовании метод не указан; UC IPM рекомендует single-sine |
| `diamondback_butts_brussels_sprouts` | Тот же переход на брюссельской капусте, отдельный опубликованный вариант | База 7,3 °C; 293 °C·дня | Такой же статус; варианты не выбираются по внешнему качеству |

Источники:

- [NC State, About Degree-Day Models](https://apples.ces.ncsu.edu/about-degree-day-models/):
  даты начала и завершения отрождения. Окно приоритетного контроля не
  переименовано в срок завершения отрождения. Пороги 350–750 для этого окна
  не подставляются вместо биологического интервала 350–1050.
- [UC IPM, таблица плодожорки](https://ipm.ucanr.edu/weather/ddtable/codling_moth.html):
  нижний/верхний пороги и single-sine horizontal. Перенос этого калькулятора
  к порогам NC State прямо помечен как адаптация, а не точное воспроизведение.
- [UW–Madison, Cabbage Maggot](https://vegento.russell.wisc.edu/pests/cabbage-maggot/):
  оттаивание почвы, база и три появления поколений. Источник не даёт основания
  автоматически назвать эти переходы пиками либо назначить 1 января биофиксом.
- [UC IPM, Diamondback Moth](https://ipm.ucanr.edu/weather/phenology-models-description/diamondback-moth/):
  Harcourt (1954) и Butts & McEwen (1981), разные растения-хозяева и суммы.

Для перевода °F·дней в °C·дни используется множитель 5/9. Пороги температуры
переводятся с вычитанием 32, а суммы — без него. Например, 300 °F·дней =
166,666… °C·дней. Для моли оставлены исходные явно опубликованные 7,3 °C
и 283/293 °C·дня, без придания дополнительной точности округлённым величинам.
Для Delia и Plutella верхний биологический порог не придуман.

## Время и доступность входов

Вход расчёта — `date`, `tmin_c`, `tmax_c` и колонка времени доступности
(по умолчанию `available_at`). `date` означает местный календарный день,
`issued_at` и время доступности должны иметь часовой пояс. Обрабатываются
только полностью завершившиеся дни строго раньше даты выпуска и только
записи, уже доступные к выпуску. Температура будущих и запоздалых записей
не читается. Неизвестное время доступности считается недоступностью.
Входные min/max должны описывать полные сутки; почасовую полноту невозможно
восстановить из двух чисел. Запись с публикацией до завершения своего дня
отклоняется: это мог быть прогноз, а не известная погода полных прошлых суток.
Время доступности может быть допущением исследовательского протокола, но его
нельзя без доказательства называть историческим временем публикации.

Точка отсчёта имеет три обязательных компонента: дата, смысл `biofix_kind`
и `biofix_available_at`. Без них возвращается явный отказ от расчёта.
Взрослый первый улов моли не заменяет дату наблюдённой когорты яиц;
для Delia не создаётся вымышленная дата оттаивания. Biofix текущего дня
не используется: запись допускается со следующего дня и лишь после своего
явного времени доступности. Полный день biofix включается в сумму —
объявленная исследовательская конвенция, а не восстановленное внутрисуточное
время начала развития.

Расчёт использует проверенный интегратор
`external_dd_benchmark.estimate_degree_days`. Когда верхний порог отсутствует
в спецификации, интеграл вычисляется без физического верхнего ограничения;
внутренняя численная граница ставится выше всех конечных максимумов и никогда
не выступает биологическим параметром.

Если переход ещё не достигнут, недоступный недавний промежуток и будущее
оцениваются фиксированным средним темпом суммы температур за последние семь
последовательных доступных дней. Пропуск внутри нужной истории вызывает
отказ: календарь не сжимается и старые дни не подбираются вместо пропуска.
Нулевой темп вызывает отказ, кроме уже достигнутого перехода. Запоздалые
версии погоды не меняют прошлое решение; дубли доступных суток требуют
предварительно выбранной версии и не склеиваются автоматически.

Предсказанная дата — первый календарный день достижения порога. `score=1`
означает попадание этой даты в окно выпуска **+3…+10 дней**, иначе `0`;
при недостатке входов — NaN. Это индикатор окна, не калиброванная вероятность.
Уведомления этот модуль не отправляет и cooldown не меняет. Расширение
постоянством последней недели — исследовательский прогноз, не архивный
оперативный выпуск погоды и не опубликованная часть биологической модели.

## Проверки и точные блокеры биологической валидации

Тесты проверяют аналитически вычислимую дату перехода при постоянной
температуре, единицы, разные типы biofix, отсутствие мнимого верхнего порога,
пропуски, нулевой темп, границы окна +3/+10, получение данных после выпуска,
незавершившиеся сутки, дубли и независимость решения от будущих температур.
Проверенный на UCANR численный интегратор не доказывает переносимость
порогов вредителя на местные поля.

| Объект | Что препятствует внешней биологической оценке |
|---|---|
| Плодожорка | В коллекции Dryad Montana и PeerJ сохранены метаданные, а не пригодная численная разметка отрождения; доступ к численным файлам не установлен. Penn State подтверждён графиками, не таблицами. Взрослый улов как biofix нельзя выдать за наблюдённое отрождение |
| Капустная муха | Нет последовательных подтверждённых Delia-учётов вместе с наблюдённым оттаиванием. Отдельные GBIF-находки не подтверждают отсутствие и начало поколения |
| Капустная моль | Нет размеченных последовательностей наблюдённая когорта яиц → взрослая особь. Даты взрослых находок не восстанавливают длительность поколения |

Таким образом, четыре ID — **реализованные адаптации стадий**, а не четыре
успешно валидированные полевые модели. Варианты не получали вымышленных
таблиц точности, синтетические тесты не объявляются полевыми результатами.

## Воспроизведение

```bash
PYTHONPATH=src .venv/bin/python -m pytest tests/test_external_thermal_stages.py -q
```

Программный вызов:

```python
from agro_phenology.external_thermal_stages import predict_stage_dates

result = predict_stage_dates(
    daily_minmax=weather,       # date, tmin_c, tmax_c, available_at
    model_id="cabbage_maggot_uw",
    biofix_date=observed_thaw_date,
    issued_at=issue_timestamp,  # timezone-aware
    biofix_kind="observed_ground_thaw",
    biofix_available_at=thaw_record_received_timestamp,
)
```

Следующий необходимый шаг для этих моделей — соответствующие реальные
исходы и точки отсчёта. Подбор порога по первым взрослым находкам не заменит
этих входов и автоматически не запускается.
